A web-based application that provides legal assistance using AI by answering user queries in simple language.

Project Overview

This project allows users to ask legal questions and receive AI-generated responses. It helps in understanding basic legal concepts and guidance without needing deep legal knowledge.

Features :-

Ask legal questions in natural language
AI-generated legal responses
Simple and user-friendly interface
Fast response system
```
Tech Stack
```

Python
Flask
HTML, CSS, JavaScript
NLP / AI Model

```
Project Structure
```
app.py – Backend server
bruh.html – Main user interface
static/ – CSS and JavaScript files
templates/ – HTML templates
requirements.txt – Python dependencies

```
Setup Instructions
```
Install dependencies

pip install -r requirements.txt

Run Backend
python app.py
Run Frontend

Open index.html in any browser (Chrome, Brave, Edge, OperaGX, etc.)
